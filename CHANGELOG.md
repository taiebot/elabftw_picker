# Changelog

## 0.1.0 - 2026-10-25

First release.

### Added
- eLabFTW in the Smart Picker: experiments and resources are searched together, most recently modified first.
- Archived entries: they are searched after the normal ones ("Load more"), or right away when a search finds no normal entry.
- Rich previews of eLabFTW links: title, excerpt, colored category and status, author, last modification date, tags, and icons for signed, locked, timestamped and archived entries.
- Per-user API key (stored encrypted); the administrator only sets the URL of the eLabFTW server.
- French translation.
